# ✈ Airline Reservation System

A full-stack Airline Reservation System developed using Flask, MySQL and Bootstrap.

## Features

- User Registration & Login
- Secure Password Hashing
- Flight Search
- Flight Booking
- Booking Cancellation
- Booking History
- PDF Ticket Generation
- User Profile
- Admin Dashboard
- Flight Management
- Booking Statistics

---

## Tech Stack

- Python
- Flask
- MySQL
- Bootstrap 5
- ReportLab
- HTML/CSS
